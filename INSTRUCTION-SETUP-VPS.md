## Шаг 1: Аренда сервера (VPS)
Вам подойдет любой недорогой VPS/VDS сервер (от 300 до 600 руб/мес или $3-6):
* **Рекомендуемая ОС:** `Ubuntu 22.04 LTS` или `Ubuntu 24.04 LTS` (64-bit).
* **Характеристики:** 1-2 vCPU, 2 ГБ RAM (минимум 1 ГБ), 20-30 ГБ SSD.
* **Провайдеры:** Timeweb Cloud, Aeza, FirstVDS, Beget, Hetzner, DigitalOcean или любой другой.

## Шаг 2: Подключение к серверу через терминал
После создания сервера хостинг выдаст вам:
* **IP-адрес сервера** (например, `194.87.123.45`)
* **Логин** (`root`)
* **Пароль** (или SSH-ключ)

Откройте терминал на своем компьютере:
* На **Windows**: откройте `PowerShell` или `Командную строку` (или программу PuTTY).
* На **macOS / Linux**: откройте стандартный `Терминал`.

Введите команду:
```bash
ssh root@194.87.123.45
```
*(Замените `194.87.123.45` на реальный IP вашего сервера)*.  
Нажмите Enter, введите пароль (при вводе символы не отображаются — это нормально) и нажмите Enter. Вы вошли на сервер!

## Шаг 3: Быстрая подготовка окружения на сервере
Выполните одну команду в терминале сервера, чтобы обновить пакеты и установить Git и Node.js 22 LTS:

```bash
apt update -y && apt upgrade -y
apt install -y curl git ca-certificates gnupg
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs
```

Проверьте установку:
```bash
node -v   # Должно показать v22.x.x
npm -v    # Должно показать v10.x.x
```

## Шаг 5: Настройка ключей (.env файл)

### 1. Получение Telegram бота и Chat ID:
1. Откройте Telegram, найдите бота **@BotFather** и отправьте ему `/newbot`.
2. Введите имя бота (например, `My Gold Trader Bot`) и юзернейм (например, `my_gold_trade_bot`).
3. BotFather выдаст **HTTP API Token** (вида `7123456789:AAFlkjw9e...`). Скопируйте его.
4. Откройте бота **@userinfobot** в Telegram и нажмите `/start`. Он пришлет ваш цифровой **Id** (например, `123456789`). Скопируйте его.

### 2. Получение ключа DeepSeek API:
1. Перейдите на сайт [platform.deepseek.com](https://platform.deepseek.com/).
2. Зарегистрируйтесь и в разделе **API Keys** нажмите **Create API Key**.
3. Скопируйте ключ (вида `sk-1234567890abcdef...`).

### 3. Создание файла `.env` на сервере:
В папке проекта выполните:
```bash
nano .env
```

Вставьте следующее содержимое (заменив значения в кавычках на свои):
```env
NODE_ENV=production
PORT=3000
HOST=0.0.0.0

# DeepSeek AI
DEEPSEEK_API_KEY="sk-ваш_deepseek_ключ"

# Telegram уведомления
TELEGRAM_BOT_TOKEN="ваш_токен_из_BotFather"
TELEGRAM_CHAT_ID="ваш_chat_id"

# Секретный токен для вебхуков TradingView (любая надежная строка)
WEBHOOK_SECRET="st_secret_tradingview_token"

# Опционально: Gemini ключ (если используете инспектор скриншотов)
GEMINI_API_KEY=""
```
Нажмите **Ctrl + O**, затем **Enter** для сохранения, и **Ctrl + X** для выхода из редактора.

## Шаг 6: Запуск сервера

Мы подготовили автоматический скрипт развертывания, который всё сделает за вас:

```bash
chmod +x deploy.sh
./deploy.sh
```

Скрипт автоматически:
1. Установит все зависимости `npm install`.
2. Скомпилирует проект `npm run build`.
3. Установит менеджер фоновых процессов **PM2**.
4. Запустит сервер в круглосуточном фоновом режиме под авто-перезапуском при сбоях и перезагрузках VPS.

Проверить, что сервер работает:
```bash
pm2 status
```
Вы увидите зеленую строку `online` напротив `st-indicator-studio`.

Сервер теперь доступен в браузере по адресу:
```
http://194.87.123.45:3000
```
*(Замените IP на адрес вашего VPS)*.

## Шаг 7: Настройка домена и бесплатного SSL (HTTPS)
TradingView требует, чтобы Webhook отправлялся по защищенному протоколу **HTTPS**.  
Для этого используется утилита **Caddy** (она автоматически выпускает и продлевает бесплатный SSL от Let's Encrypt за 10 секунд).

1. Направьте ваш домен (например, `gold.mytrader.ru`) в DNS на IP-адрес вашего сервера (A-запись).
2. На сервере установите Caddy:
   ```bash
   apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
   curl -1sLF 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
   curl -1sLF 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | tee /etc/apt/sources.list.d/caddy-stable.list
   apt update
   apt install caddy -y
   ```
3. Откройте конфиг Caddy:
   ```bash
   nano /etc/caddy/Caddyfile
   ```
4. Вставьте 3 строчки:
   ```caddy
   gold.mytrader.ru {
       reverse_proxy 127.0.0.1:3000
   }
   ```
   *(Замените `gold.mytrader.ru` на ваш реальный домен)*.
5. Перезапустите Caddy:
   ```bash
   systemctl restart caddy
   ```
Все! Теперь ваш сервер доступен по безопасному адресу `https://gold.mytrader.ru`.

## Шаг 8: Настройка алертов в TradingView

1. Откройте TradingView, выберите график золота (`XAUUSD` или `GOLD`) на таймфрейме `15m` (а также при желании на `1h` или `4h`).
2. Добавьте на график ваш скрипт индикатора **S&T Super Indicator v6**.
3. Нажмите кнопку **Создать оповещение (Create Alert)**:
   * **Условие (Condition):** Выберите ваш индикатор `S&T Super Indicator v6`.
   * **Действие:** Выберите сигнал покупки/продажи или `Any alert() function call`.
   * **Частота:** `Раз за бар при закрытии` (Once Per Bar Close) — это защитит от ложных шпилек!
   * Во вкладке **Уведомления (Notifications)**:
     * Поставьте галочку **URL вебхука (Webhook URL)**.
     * Вставьте URL вашего сервера:
       ```
       https://gold.mytrader.ru/api/webhook/tradingview?token=st_secret_tradingview_token
       ```
   * Во вкладке **Настройки (Settings)** в поле **Сообщение (Message)** вставьте JSON:
     ```json
     {
       "ticker": "{{ticker}}",
       "action": "{{strategy.order.action}}",
       "price": {{close}},
       "timeframe": "{{interval}}",
       "comment": "{{strategy.order.comment}}",
       "time": "{{time}}"
     }
     ```
4. Нажмите **Создать (Save)**.

## Шаг 9: Проверка работы и получение отчетов 09:00 / 15:00

1. Откройте панель сервера в браузере: `https://gold.mytrader.ru`
2. Перейдите во вкладку **«🏆 Золото & DeepSeek AI (09:00 / 15:00)»**.
3. Нажмите оранжевую кнопку **«Сгенерировать План Сейчас»**:
   * Сервер соберет данные по таймфреймам (15m, 30m, 1h, 4h).
   * Сопоставит их с актуальным календарем новостей США на сегодня.
   * Сформирует торговый план через DeepSeek AI.
   * Отправит готовое сообщение в ваш Telegram!
4. **Автоматический режим:**
   * Каждый день ровно в **09:00 МСК** (утренний план) и в **15:00 МСК** (пре-маркет США) сервер будет автоматически формировать и присылать свежий план в Telegram.
   * При появлении важных новостей дня (инфляция CPI, решение ФРС, NFP) используйте блок **«Опубликовать Важное Макро-Событие»** для мгновенного пересчета торгового плана.
